ستۆدیۆی کتێبخانە - پاکێجی ئەپی ڕاستەقینە (PWA)
================================================
ئەم فۆڵدەرە ئەگەر بخرێتە سەر هەر هۆستێکی بەخۆڕایی، دەبێتە ئەپێکی ڕاستەقینە کە بێ ئینتەرنێت کار دەکات:

  1. بڕۆ بۆ https://app.netlify.com/drop  (یان GitHub Pages / Cloudflare Pages)
  2. هەموو ناوەڕۆکی ئەم فۆڵدەرە (یان فایلی zip) فڕێ بدە ناوی.
  3. لینکەکە لەسەر ئایپاد/ئایفۆن بکەرەوە بە Safari.
  4. دوگمەی هاوبەشکردن (Share) → "Add to Home Screen". ئێستا ئایکۆنی خۆی هەیە و وەک ئەپ دەکرێتەوە.

یەکەم جار کە کرایەوە، هەموو شتێک خۆی دەخاتە ناو ئامێرەکەت و دواتر بێ ئینتەرنێت دەکرێتەوە.
تێبینی: کتێبەکانت لەسەر هەمان ئامێر و هەمان لینک دەمێننەوە. بۆ گواستنەوە لە ئامێرێکەوە بۆ یەکێکی تر، بەشی «هاوکاتکردن» بەکاربهێنە.
